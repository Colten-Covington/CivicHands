# Contributing to CivicHands

CivicHands is open-source and welcomes bug reports, product ideas, accessibility improvements, design work, documentation, and code contributions.

## Before opening a pull request

1. Open or comment on an issue for substantial product changes so the safety and privacy impact can be discussed first.
2. Create a branch from `main`.
3. Keep the change focused and include a clear description of the user-facing outcome.
4. Run `npm run build` and `npm run lint`.
5. Never commit credentials, real private addresses, vulnerable-person details, or production records.

## Product guardrails

- Public cleanup, city hazards, and private neighbor support are separate service lanes.
- Do not expose exact residential locations for neighbor-support requests.
- Do not add points, rankings, streak pressure, or competitive leaderboards.
- Do not encourage untrained volunteers to enter traffic or handle utilities, hazardous materials, or suspended trees.
- New data collection must have a clear purpose, retention plan, and privacy treatment.
